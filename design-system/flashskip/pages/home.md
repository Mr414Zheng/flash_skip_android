# FlashSkip Home Page Specification

> 继承：[MASTER.md](../MASTER.md)  
> 视觉基准：[视觉方向.png](../../../视觉方向.png)  
> 页面：唯一首页 / 单纵向滚动控制台

## 1. 页面目标

用户打开页面后 3 秒内回答：

1. 服务当前是否可用；
2. 哪三个应用已启用；
3. 最近一次动作是否成功。

## 2. 页面顺序

顺序固定，不提供拖动或自定义：

1. `FlashSkip` 页面标题
2. `ServiceStatusBlock`
3. `目标应用` + 3 个 `TargetAppRow`
4. `最近执行` + `ExecutionTimeline`
5. `PrivacyFooter`

不使用 Top App Bar 操作项、底部导航、悬浮按钮、标签页或溢出菜单。

## 3. 默认 390 × 844 布局

| 区域 | 规范 |
| --- | --- |
| 页面水平边距 | 24 dp |
| 顶部系统 Insets 后留白 | 24–32 dp |
| 标题与服务状态 | 28 dp |
| 服务状态内部行距 | 8 dp |
| 服务状态与目标应用 | 40 dp |
| Section Header 与内容 | 20 dp |
| 目标应用行高度 | 最小 96 dp，可随字体增长 |
| 应用行分隔线 | 1 dp，`divider`，从页面内容左边到右边 |
| 目标应用与最近执行 | 32 dp |
| 时间线条目高度 | 最小 76 dp，可随文字增长 |
| 最近执行与隐私页尾 | 28 dp |
| 页面底部 Insets 前留白 | 24 dp |

### Section Header

- 蓝色标记：4 × 20 dp，圆角 2 dp。
- 标记与标题间距：12 dp。
- 标题使用 `type.sectionTitle`。
- 蓝色标记纯装饰，不进入 TalkBack。

## 4. ServiceStatusBlock

### 4.1 默认结构

- 第一行：状态图形 + `type.statusTitle`。
- 第二行：启用数量 + 安全承诺，使用 `type.body`。
- 第三行：最近成功时间与应用，使用 `type.body` 或 `metadata`。
- 状态块不使用卡片背景和阴影。
- 正常状态没有操作按钮，也没有主服务开关。

### 4.2 状态矩阵

| 状态 | 标题 | 说明 | 第三行/操作 | 语义 |
| --- | --- | --- | --- | --- |
| 正常 | `服务运行正常` | `已启用 3 个目标应用 · 不确定时不会执行` | `最近成功：今天 08:42 · 淘宝` | 绿色圆点 + 完整文字 |
| 未开启 | `无障碍服务未开启` | `开启后，仅在目标应用启动后的 10 秒内检查关闭节点` | 主色按钮 `前往系统设置` | 琥珀图标 + 文字 |
| 异常 | `服务状态异常` | `系统显示已开启，但服务当前不可用` | 主色按钮 `检查系统设置` | 红色图标 + 文字 |
| 正在确认 | `正在确认服务状态` | `通常会在短时间内自动更新` | 小型进度指示，无按钮 | 蓝色进度 + 文字 |

### 4.3 最近成功规则

- 有成功记录：显示绝对/相对时间和应用名。
- 无成功记录：显示 `尚无成功记录`，不显示 `--`。
- 不把 `已放弃` 计为成功。
- 时间变化不触发布局跳动。

## 5. TargetAppRow

### 5.1 默认结构

从左到右：

1. 56 dp 官方应用图标；
2. 16 dp 间距；
3. 应用名与说明，填充剩余宽度；
4. 12 dp 间距；
5. Material 3 Switch，视觉尺寸约 52 × 32 dp、触控区域至少 48 × 48 dp。

应用顺序固定：QQ音乐 → 淘宝 → 京东。

### 5.2 文案状态

| 状态 | 次级文案 | Switch |
| --- | --- | --- |
| 已启用且服务正常 | `已启用 · 1 条规则` | On |
| 已停用 | `已停用` | Off |
| 已启用但服务未开启 | `已启用 · 服务开启后生效` | On，仍可操作 |
| 规则不可用 | `自动关闭不可用 · 请先采集规则` | Disabled |

### 5.3 交互语义

- Switch 只控制自动关闭；“采集规则”“采集完成”等按钮是独立 TalkBack 焦点，不允许整行切换。
- 示例朗读：`淘宝自动关闭开关，已开启`，随后是独立的 `继续采集` 按钮。
- 垂直滚动手势优先；短暂触碰不能误切换。
- 切换后立即更新文字与状态，并持久化；不弹确认对话框。
- 按压使用 Material state layer，不缩放整行。

### 5.4 采集控制与内联规则卡

- 应用信息行下方依次放采集说明、采集/取消/完成操作和可选规则卡；不新增详情页或 Bottom Sheet。
- 规则卡使用 `surfaceVariant`、12 dp 圆角，显示 Candidate/Ready/Stale、单次有效样本进度、非门槛唯一性记录、应用版本和限长选择器摘要。
- 200% 字体时操作纵向排列，卡片与行高由内容撑开，关键 CTA 不得横向溢出。

## 6. ExecutionTimeline

### 6.1 排列

- 最多 20 条，最新在上。
- 每条由左侧时间线节点、连接线与右侧两行文字组成。
- 结果标题使用 `type.rowTitle`；详情使用 `type.metadata`。
- 连接线只表达序列，不表达执行成败。
- 条目之间用 1 dp 分隔线加强横向扫描，分隔线从文字列开始。

### 6.2 结果语义

| 类型 | 标题 | 详情示例 | 节点 |
| --- | --- | --- | --- |
| 节点点击成功 | `已关闭` | `节点点击 · 今天 08:42 · TB-splash-01` | 主色蓝 |
| 中心手势成功 | `已关闭` | `中心手势 · 昨天 18:05 · JD-splash-01` | 主色蓝 |
| 安全放弃 | `已放弃` | `匹配存在歧义 · 昨天 22:16 · QQM-splash-01` | 中性灰 |
| 执行失败 | `执行失败` | `节点已失效 · 今天 07:31 · TB-splash-01` | 错误红 + 错误图标 |

`匹配存在歧义` 必须使用正确文字；选定概念图中的 ImageGen 字形误差不是正式文案。

### 6.3 空状态

- 标题：`暂无执行记录`
- 说明：`成功关闭、执行失败或匹配后放弃时会显示在这里。`
- 不使用插画、动画或虚构日志。
- 空状态左对齐到时间线文字列，保持页面节奏。

## 7. PrivacyFooter

- 顶部 1 dp 分隔线。
- 左侧 24 dp `ShieldOutlined`，右侧文案：`完全离线 · 不截图 · 规则字段仅存本机`。
- 图标为装饰；整句文字作为一个语义节点。
- 存在采集样本时，下方显示独立的 `清除全部采集数据` 文本按钮。

## 8. InlineAction

仅用于服务未开启与异常状态。

| 属性 | 规范 |
| --- | --- |
| 高度 | 48 dp |
| 水平内边距 | 16 dp |
| 圆角 | 8 dp |
| 背景 | `primary` |
| 内容 | `onPrimary` |
| 字体 | `type.label` |
| 文案 | `前往系统设置` 或 `检查系统设置` |

按钮必须明确外部跳转，不使用含糊的 `立即开启`。

## 9. 响应式与大字体

### 小屏 `< 360 dp`

- 页面水平边距降至 16 dp。
- 应用图标降至 48 dp。
- 日志详情允许规则 ID 换到下一行。
- 不缩小正文到 14 sp 以下。

### 平板 `≥ 600 dp`

- 内容最大宽度 560 dp 并居中。
- 仍保持单列；不把应用列表和日志拆成左右栏。
- 页面左右留白承担视觉安定感。

### 字体 200%

- 应用行与时间线条目改为内容驱动高度。
- Switch 与图标顶部对齐或垂直居中，以实际可读性为准。
- 服务说明、恢复按钮和应用名不得截断。
- 规则 ID 可以换行，但必须保持完整可读。

## 10. 深色模式覆盖

- 页面结构、间距、字号和组件尺寸不变，只替换 Master 中的 Dark Tokens。
- 分隔线使用 `#333741`，不得直接沿用 Light 的 `#EAECF0`。
- 应用图标保持官方颜色；必要时使用 Dark `divider` 1 dp keyline。
- Switch 使用 Dark `primary`，不通过增加发光或阴影提升可见性。

## 11. 视觉验收

实现前后的比对优先级：

1. 页面信息顺序与扁平清单结构；
2. 24 dp 水平边距、应用图标与文字基线、Switch 对齐；
3. 标题、状态、分节标题、行标题、元数据的字体层级；
4. 蓝色标记、绿色服务圆点、蓝/灰时间线节点的语义区分；
5. 分隔线位置、行高和区块留白；
6. 浅色与深色对比度、大字体和 TalkBack 行为。

必须验证视口：360 × 800、390 × 844、412 × 915、600 × 960，以及至少一个横屏视口。

## 12. 页面禁止项

- 页面顶部加入 Logo 插画、口号、统计数字或设置按钮。
- 把服务状态放进大卡片，或给每个应用单独加卡片。
- 在日志列表增加筛选、搜索、折叠或详情页入口。
- 为 `已放弃` 使用红色警报样式。
- 在服务正常时显示 `前往系统设置` 按钮。
- 为页尾隐私声明添加点击箭头或外链暗示。
