# SDD-007：规则管理

状态：P4 管理政策及后续最小生产修复已获授权，本地契约验收通过。基线 main `40e6080`，日期 2026-10-14。见 [计划](plan.md)、[任务](tasks.md)、[验证](validation.md)。

## 目标与当前实现

RuleCaptureCoordinator 通过同一操作锁协调启停、保存和删除；HomeViewModel 保留失败动作供明确重试。单目标删除先停用，后删除该目标的样本、活动会话和语义证据；全部删除依次停用样本、已存开关、会话所指目标，之后清空采集库。两个 DataStore 没有跨库事务。记录保留。

基线已经符合大部分删除顺序，但读取 IO 可被 store 回退为空，导致管理操作继续；ViewModel 删除重试只记目标／全部，不绑定数据范围，可能删除失败后新数据。这些是实现事实，是否违反政策由独立反例验证。

本轮按续授权完成最小生产修复，保留既有公开管理入口和数据格式；不提交、推送或创建 PR，不改依赖／构建／远端设置。SDD-001/T-12 未完成并停止，不开展设备或 P5 工作。

## 已确认政策

- RM-01：批量第 N 次停用失败后停止；前面已提交停用保留，后面不继续；全部采集数据保留到所有停用成功。
- RM-02：首次删除绑定数据范围；相关样本、会话、语义证据变化后旧重试失效，需重新确认。单目标范围不包含其他目标变化；全删除包含所有目标和残留开关范围。本次操作自身已完成的停用不使其失效。历史执行记录不属于删除范围。
- RM-03：沿用显式启用、删除保留记录和取消传播。不可用存储须遵守 SDD-006/AC-02、SDD-006/AC-04，不能以空库替代后继续破坏性操作。

## 验收条件

### AC-01 显式启停与目录门禁

开启仍要求无阻塞采集、目录源样本同步、目标 READY 且最终规则非空；关闭可在阻塞采集期间进行，不能删除证据。删除完成但目录尚滞后时开启被拒绝，目录同步且目标已无规则后仍拒绝；不得重放被拒绝的开启。保留 SDD-001/AC-06 与 SDD-002/AC-06。

### AC-02 单目标删除与隔离

先提交目标停用，再删除该目标样本、匹配目标的会话和语义证据。其他目标的会话／样本／开关／证据以及所有执行记录保留。停用失败不尝试写采集库；采集删除失败保留原载荷及已提交停用。不存在目标和重复删除维持安全、幂等结果，不要求每次无底层写入。

### AC-03 全部删除与部分失败

去重处理样本目标、已存开关目标和活动会话目标，包含只有开关或只有会话的目标。按当前确定顺序逐一关闭，不增加批量 API。首个失败停止，不回滚已经停用的目标，不继续后面目标，不清除任何采集载荷。全部停用成功才清空采集库；最终写失败保留完整载荷及所有已关闭开关。显式重试可完成，不删除历史记录。

### AC-04 并发、取消与持久化

保存、删除、开启在同一锁下按实际获得锁的顺序执行：删除后旧保存不得恢复已删除会话；保存后排队删除清除刚保存的目标样本；开启不能使用旧目录重新打开已删除目标。取消须传播并释放锁；提交前不修改，两个提交之间保留停用和原载荷，提交后不回滚。真实磁盘重开验证实际提交边界，不声称跨库原子性。

### AC-05 删除重试范围

首次操作后失败，未变化的数据可明确重试，包括本操作已完成的部分停用。相关样本、会话或语义证据发生变化时，旧重试返回过期反馈，关闭重试且不得再写开关或采集库。全删除后新增目标／残留开关同样使旧重试失效。无关目标变化不影响单目标重试，单独追加执行记录不影响删除重试。用户重新确认调用删除入口可以作用于最新范围。

通过 ViewModel 公开入口固定此结果；内部 RuleDeletionRequest 绑定一次确认及其重试，校验在协调器操作锁内完成，不新增持久化版本或公开重试 token 接口。跨进程重试恢复不是本期能力。

### AC-06 ViewModel 反馈与输入

IO 失败显示 STORAGE 并允许明确重试，持续失败不显示成功；成功清理旧反馈和重试。新成功动作清除旧重试，新失败动作替换旧重试。已有主动操作执行期间的重复／冲突输入不排队；取消 ViewModel 作用域不能把部分删除伪报为成功。ViewModel 验证不等于 Compose 控件验证。
