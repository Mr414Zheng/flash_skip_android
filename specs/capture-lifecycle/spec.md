# SDD-004：采集生命周期

状态：五项政策已于 2026-10-13 确认，其余参数沿用 main `34dc102`。首轮仅授权规格、离线测试、证据与必需清单；用户后续已明确授权五项政策的最小生产修复与真实服务集成所需内部接缝。任务见 [任务](tasks.md)，实施见 [计划](plan.md)，实际结果见 [验证记录](validation.md)。

## 目标与职责

平台负责验证窗口并生成证据，RuleCaptureCoordinator 在操作锁内校验会话并提交状态；HomeViewModel 处理明确外跳与返回。沿用现有公共 API 与存储格式。保存资格、先关闭后保存、失败重试和显式启用引用 SDD-001/AC-01～AC-08，不给 `finish` 增加硬截止。

## 状态与转换矩阵

| 当前阶段 | 合法输入与下一阶段 | 拒绝或终止边界 |
| --- | --- | --- |
| 无会话／FAILED | requestStart → CONFIGURING | 阻塞中的重复开始拒绝；新 ID 不复用旧 ID |
| CONFIGURING | 同 ID 配置确认 → WAITING_FOR_TARGET | 配置超时、取消、失败后不能外跳；配置改变不算离开 |
| WAITING_FOR_TARGET | 首次正式目标验证 → OBSERVING_CLICK；首次快速真实点击 → CAPTURED；候选 → AWAITING_CONFIRMATION | 旧 ID 无副作用；返回且已离开 → RETURNED_BEFORE_TARGET |
| OBSERVING_CLICK | 同目标窗口更新留在本阶段；点击 → CAPTURED；候选 → AWAITING_CONFIRMATION | 其他目标拒绝；同目标窗口更新不延长期限；返回无证据 → DISMISS_NOT_CAPTURED |
| AWAITING_CONFIRMATION | 匹配真实点击升级 → CAPTURED；明确 finish 保存并清会话 | 返回关闭监听；不能自动保存、开启或冒充真实点击 |
| CAPTURED | 明确 finish 保存并清会话；返回仅清离开标记 | 重复点击不能重新采集；保存沿用 SDD-001 |
| 任意当前会话 | 合法取消清会话；通用 fail 或到期结算 → FAILED | 通用 fail／取消／超时仍可清载荷，不套用断连保留政策 |

## 验收条件

### AC-01 启动与配置

重复开始拒绝且零业务变化；配置确认后才可外跳。配置失败、取消、等待配置超时或过期的旧配置通知不能推进当前会话。新开始生成递增 ID；没有会话时的通知无副作用。

### AC-02 目标进入

首次经过平台正式验证的目标建立包、Activity、窗口和进入单调时间。等待目标时允许首次快速点击直接形成证据。同目标更新窗口不延长观察期限；其他目标、非法阶段、旧 ID 拒绝且不改变证据。

### AC-03 离开与返回

配置变化不作为真实离开。明确离开后返回按矩阵结算；待确认停止点击监听，已采集不自动保存。离开标记写失败时可用同会话本进程的 observedDeparture 补足，旧 ID 或其他会话不能借用。诊断提供者异常不得改变业务结算；取消传播。

### AC-04 期限与双时钟【已批准政策】

配置完成、目标识别、采集、候选记录与升级，在取得操作锁后按当前阶段单调期限检查；截止前可提交，等于或超过截止不得提交新证据或推进阶段，保留状态交由超时流程结算。等待锁跨期限也必须拒绝。`finish` 仍按 SDD-001 串行裁决，不增加保存硬截止。

配置 2 秒、等待目标 90 秒、观察 15 秒、待保存 600 秒为基线参数。阶段提交前的存储等待消耗新阶段预算；同一阶段键不能重发预算。首次恢复按墙钟计算剩余并限制在阶段预算内，阶段开始在未来则剩余为零；之后墙钟前跳或回拨不改变单调期限。过期操作以完整 session/phase/start/deadline 键隔离旧定时器。成功升级后的新 CAPTURED 阶段仍沿用基线 600 秒预算。

### AC-05 断连与恢复【已批准政策】

等待目标与观察点击终止为服务不可用。未过期且有效的 CAPTURED／AWAITING_CONFIRMATION 保留载荷，关闭候选点击监听，继续阻塞自动执行并等待明确保存；不得自动保存或开启。过期载荷按完成超时结算。服务首次状态发射遵守相同分类；CONFIGURING 恢复只用原有剩余配置时间，不重发 2 秒。通用 fail、取消及超时仍可清载荷。

### AC-06 异步隔离与故障

旧准备通知、扫描、窗口重试、写入、断连和到期结果不能影响新会话。IOException 映射为可报告的失败，保留未恢复错误，只有相应成功结算清除；取消继续传播，不转成功，不回滚已提交状态。后台观察不可用只记诊断并等待阶段期限，不等价于业务失败或目标不存在。

### AC-07 服务配置、暂停与释放

真实服务采集期间配置所需事件并阻塞自动执行；替换自动引擎后必须重新同步当前暂停状态。interrupt／destroy 取消观察、重试与定时结算并释放资源。观察循环每轮结束后等待 200ms，总预算 107 秒，不因慢观察积压任务。组件测试只能证明所驱动组件，真实服务及实际系统事件必须分别登记。

## 完成边界

失败保持可见，不忽略或放宽预期。规格测试交付不等于 P3 验收通过；无设备或 Compose 控件验收，SDD-001/T-12 未完成且继续停止。本次续授权包含最小生产修复和内部接缝；不包含提交、推送、PR、依赖、构建或远端设置变更。
