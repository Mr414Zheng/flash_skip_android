## 目标与边界

明确哪些采集样本可产生可执行规则，以及规则目录如何校验、发布和被消费。沿用领域规则、目录和应用协调器职责，不变更公开端口、持久化模型、数据格式或依赖，不迁移或删除既有样本，不自行改写目标开关。

离线测试使用现有 JUnit 4、协程测试与 Robolectric。SDD-001 的保存及显式启用契约继续有效；其 75 例是回归基线，不能代替本规格专项验收。SDD-001/T-12 未完成并保持停止，不开展设备或京东复现验证。

## 基线与当前实现

以下区分 `ad01dc7` 基线行为与本轮已授权修复；实际离线测试结果见验证记录：

- [RuleCandidateAnalyzer](../../app/src/main/kotlin/com/zhenghuaizhi/flashskip/domain/rulecapture/RuleCandidateAnalyzer.kt) 以 1 份合格样本、0 份采集前唯一性证据作为门槛；每组最多 3 个选择器，按最近采集时间排列；本机规则启动延迟 0、冷却 10 秒、不绑定版本。
- 基线仅对通用关闭文案及数字倒计时设置结构限制，其他纯文本、纯描述或文本加描述曾可生成 READY；本轮分析器已统一要求稳定结构，无结构输入保留为候选，备用选择器也须满足同一条件。
- [RuleValidator](../../app/src/main/kotlin/com/zhenghuaizhi/flashskip/domain/rules/RuleValidator.kt) 保留字段、动态文本、祖先距离、时间和 ID 校验，并新增每个可执行选择器的稳定结构门禁；内置及本机目录沿用统一校验。[RuntimeSelectorPolicy](../../app/src/main/kotlin/com/zhenghuaizhi/flashskip/domain/rulecapture/RuntimeSelectorPolicy.kt) 同时拒绝空白资源和祖先 ID 提供稳定结构。
- [CompositeRuleCatalog](../../app/src/main/kotlin/com/zhenghuaizhi/flashskip/domain/rules/CompositeRuleCatalog.kt) 根据样本异步计算，使用 `mapLatest` 与计算间让出执行权；规则、分析和源样本共同发布。本机规则优先，组合校验冲突时整组回退至内置规则，故 READY 分析不保证最终目录仍有该目标规则。

## 验收条件

### AC-01 样本资格与门槛

给定目标和采集样本，1 份合格样本即可支持规则，不强制要求采集前唯一性证据；实际执行仍须运行时唯一匹配。错误目标、负采集耗时、空 Activity、安全政策拒绝的样本不贡献规则。空节点、没有可见且有可用边界的动作节点时不能生成规则。

同一主选择器的样本按稳定键分组，Activity 集合来自本组；最近样本决定展示名称，规则组按最近采集时间倒序。不同规则组不得混入彼此的 Activity 或启动证据。

### AC-02 可执行选择器必须有稳定结构【已批准政策】

每个可执行选择器必须具有非空白且不以 `android:` 开头的资源 ID，或具有非空白、非 `android:` 的稳定祖先 ID 及合法距离。纯文本、纯描述、文本加描述只能保留为候选，不因运行时可能唯一或已有人工确认而提前成为 READY。

此条件适用于所有可执行目录入口，包括本机分析、统一校验及内置规则；不能仅修改分析器而保留内置绕过路径。保留既有样本和存储开关；没有合格规则时不得执行。候选状态不隐含删除、迁移或禁用存储写入。

### AC-03 动态文本与动作目标

倒计时文本放宽必须有稳定结构；纯数字还须通过现有关闭语义安全政策。数字节点到实际动作节点之间须有关闭语义，不得借用动作链之外的外层关闭控件。数字节点可通过合法动作祖先执行，祖先距离与动作祖先距离均为 1～4。

保留当前转换边界：稳定结构可放宽纯数字；“跳过”倒计时只有稳定祖先时放宽，否则保持精确匹配。普通页面文案不能因包含“跳过”或数字而匹配倒计时。不可见或边界无效的目标及约束祖先不能匹配。

### AC-04 校验、优先级与冲突回退

拒绝空 ID、错误包名、无 Activity、空选择器及空条件、非法动态文本、非法祖先/动作距离、负启动延迟和冷却；重复规则 ID 使整组校验失败。内置规则整组无效时目录为空。

单条非法本机规则先过滤；合法本机规则排在内置规则之前。组合后发生 ID 冲突时回退整组内置规则，影响所有本机目标，不仅是冲突目标。分析、源样本仍需保持一致，不把 READY 分析当作最终规则存在的证明。

### AC-05 目录发布一致性

快照中的规则、目标分析和源样本必须来自同一批计算；较旧计算不能在较新结果之后重新发布，删除样本后不得恢复旧规则。仅采集会话变化、样本未变时不重算规则。测试须观察中间发布顺序及最终快照，而非只验证最后一次读取。

### AC-06 版本与显式启用

本机规则继续不绑定版本；绑定版本的规则严格比较 `versionName + versionCode`，未知实际版本不匹配绑定规则。规则和目标索引保持输入优先级，复制快照后索引对应新规则。

启用须同时满足：无采集阻塞、目录源样本与存储同步、分析 READY、最终目标规则非空。目录发布不得自行启用，也不得重放曾拒绝的开启请求；沿用 SDD-001/AC-06。目录资格的变化由 SDD-003/AC-03 定义对正在执行会话的影响。
